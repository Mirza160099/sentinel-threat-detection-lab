# Incident Triage Playbook

## 1. Validate
Confirm alert logic, affected identity, timestamps, IP, device and authentication result.

## 2. Enrich
Review geolocation, sign-in history, MFA context, endpoint status and related audit events.

## 3. Scope
Determine whether activity is isolated or affects additional users/devices/IPs.

## 4. Contain
For confirmed compromise: revoke sessions, reset credentials, require MFA/re-registration, block malicious indicators where appropriate.

## 5. Eradicate / Recover
Remove persistence, validate account permissions and monitor for recurrence.

## 6. Document
Record evidence, timeline, decisions, severity, actions and lessons learned.
